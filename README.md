## Hosting Locally with Cloudflare Tunnel

To use this addon on other devices (like a TV or phone) or to share it, you can host it securely using 
Cloudflare Tunnel.

1. **Download `cloudflared`** for your operating system from the [official GitHub 
releases](https://github.com/cloudflare/cloudflared/releases).

2. **Run the tunnel** command. 
   cloudflared tunnel --url http://127.0.0.1:7050


3. **Copy the URL** generated by Cloudflare
